# Приют для животных

Сайт приюта, перенесённый на React и Vite. Сохранены исходные тексты, изображения и адреса страниц.

## Запуск

Требуется Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Публикуйте содержимое этой папки; относительные пути позволяют размещать сайт в подкаталоге, в том числе на GitHub Pages.

## Структура

- `src/components/` — секции главной и общий подвал.
- `src/App.jsx` — страницы, меню, карточки, слайдер, пагинация и окна питомцев.
- `src/data/pets.js` — общие данные и пути к существующим изображениям.
- `src/styles.css` — адаптивные стили и стили компонентов поверх исходного `style.css`.
- `assets/` — исходные изображения и данные питомцев.

Каталог доступен по адресу `pages/our_pets.html`, страница Jennifer — `pages/pets/pet_jennifer.html`. Каталог содержит 18 питомцев без повторения: 8, 6 или 3 карточки на странице в зависимости от ширины экрана. Количество страниц вычисляется по числу анкет.

HTML-страницы находятся в `pages/`; устаревшие JS и CSS удалены.
Десять новых анкет — демонстрационные: имена, возраст и описания придуманы для наполнения сайта, медицинские сведения требуют уточнения. Фотографии загружены с Unsplash и хранятся локально в `assets/images/`. Перед публикацией реального каталога замените эти анкеты подтверждёнными сведениями приюта.
